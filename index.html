Under the Hood

VoiceFlow isn't just another wrapper. It is a completely native, bare-metal application designed for users who demand extreme performance.

Powered by Qwen TTS

Integrating the state-of-the-art Qwen audio models, VoiceFlow understands context, nuance, and natural speech patterns better than traditional voice assistants. Coupled with a dedicated Python sidecar, model inference happens locally on your machine—no cloud latency, no subscription fees.

  • ✓ Ultra-low latency voice synthesis
  • ✓ Highly accurate real-time transcription
  • ✓ Zero data sent to external servers

Built with Tauri & Rust 🦀

Electron is heavy. VoiceFlow uses Tauri, leveraging the system's native webview wrapped in an incredibly fast Rust backend. This means the application uses a fraction of the RAM while maintaining a beautiful, fluid web UI.

  • ✓ Minimal memory footprint (< 50MB idle)
  • ✓ Lightning-fast startup times
  • ✓ Deep OS integration and hotkeys
